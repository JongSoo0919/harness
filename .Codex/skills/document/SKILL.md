# Document

## Rules

- Update only relevant docs.
- Do not rewrite unrelated documents.
- Keep docs consistent with code and decisions.
- Never include secrets.
- Fill required work-output sections. Use `none`, `not applicable`, `unverified`, or `deferred` with a reason instead of blanks.
- Extract reusable knowledge to wiki drafts.
- Collect failure lessons.
- Wiki promotion is manual only. Scripts validate; humans approve.
