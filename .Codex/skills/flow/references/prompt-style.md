# Prompt Style

Default style: Caveman Lite.

- Conclusion first.
- Short sentences.
- Remove greetings and filler.
- Preserve technical accuracy.
- Preserve code, logs, commands, and error messages.
- Do not compress so much that meaning is lost.
- Ask when unclear.

Prompt shape:

1. Goal
2. Input
3. Constraints
4. Output
5. Verification
6. Stop conditions
