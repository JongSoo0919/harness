# Wiki

Reusable knowledge extracted from work outputs.

## Structure

```text
docs/wiki/
├── drafts/       # auto-extracted drafts
├── lessons/      # approved failure lessons
├── operation/    # approved operational knowledge
├── development/  # approved development knowledge
└── onboarding/   # approved onboarding knowledge
```

## Rules

- Drafts are not final wiki documents.
- Drafts require human review before promotion.
- Promotion requires final human approval.
- Never store secret, token, password, or key values.
- Keep source work output paths in promoted documents.
- Use `promotion-guide.md` for promotion rules.
